# ☁️ Projeto: Roteiro de Entrevista — Profissional de Cloud Computing

Este repositório contém o código-fonte de uma página web estática desenvolvida para a coleta de dados de uma entrevista acadêmica. O projeto foi estruturado como parte das atividades do curso de **Ciência da Computação** na **PUC Minas**.

O objetivo principal da página é fornecer uma interface limpa, moderna e direta para que um profissional atuante na área de *Cloud Computing* possa responder a um questionário estruturado sobre sua carreira, desafios práticos, uso de Inteligência Artificial e perspectivas para o mercado.

---

## 🚀 Funcionalidades

* **Design Responsivo & Moderno:** Interface limpa adaptável para dispositivos móveis e desktops, utilizando tipografia moderna (`Syne` e `DM Sans`).
* **Seção de Identificação:** Coleta automatizada de dados básicos do entrevistado (Nome, Perfil profissional como LinkedIn/GitHub e Data da entrevista).
* **Questionário Dividido em Blocos Temáticos:**
  * **Bloco 1:** Trajetória e área de atuação.
  * **Bloco 2:** Desafios técnicos e não técnicos do dia a dia.
  * **Bloco 3:** Competências valorizadas, mercado e provedores utilizados (AWS, Azure, GCP).
  * **Bloco 4:** O futuro da computação em nuvem, conselhos de carreira e o impacto da IA na rotina.
* **Integração Backend Serverless:** Envio automatizado dos dados do formulário diretamente para o e-mail do administrador através da plataforma **Formspree**.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica do formulário e das seções.
* **CSS3:** Estilização customizada utilizando variáveis CSS, efeitos de foco (*focus states*) e padrão visual escuro/claro integrado (*Hero section* e cartões).
* **Formspree API:** Serviço de processamento e recebimento de formulários via requisição `POST`.
* **GitHub Pages:** Hospedagem gratuita e deploy automatizado da aplicação.
